# 📦 Bombino Express

## Providing Swift, Safe, and Secure Logistics for the Modern World.

Bombino Express is an innovative platform designed as a premium, full-stack logistics solution that provides swift, safe, and secure services to businesses globally. Our mission is to empower our customers by
providing exceptional logistic solutions in today's digital world.

## Core Features

- **Editorial Scrollytelling**: An immersive "Services" experience with sticky layout mechanics, ensuring a smooth user experience across all devices and screen sizes.
- **Global Traffic Visualization**: A custom-coded, high-fidelity SVG dot-matrix map that displays real-time flight paths, allowing for easy tracking of shipments globally.

- **Asymmetrical Bento Design**: Modern, responsive grids designed to highlight high-impact value propositions, ensuring a visually appealing and user-friendly interface.
- **Performance-First**: Optimized using Next.js 14/15, Tailwind CSS, and Framer Motion for ultra-smooth interactions and performance.

## Design Language

The design language of Bombino Express features a primary palette that is both modern and functional. The key colors used are:

- **Admiralty Dark (#112330)** - For authority and depth, creating a high-quality user experience.
- **Dispatch Amber (#F2A123)** - For energy and action, highlighting the necessary attention to detail in all our designs.

## Tech Stack

Bombino Express is built using a variety of technologies:

- [Next.js](https://nextjs.org/)
- [React](https://reactjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Lucide React](https://lucide.dev/react)

## Getting Started

To get started with Bombino Express, follow these steps:

1. Clone the repository to your local machine using `git clone <repo_url>`.
2. Navigate into the project directory with `cd`.
3. Install all dependencies by running `npm install` in terminal or command line.
4. Start the development server with `npm run dev`.
5. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. You can start editing the page by modifying `pages/index.js`. The page will automatically reload if you make edits!
